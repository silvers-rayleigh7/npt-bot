# Отчёт по проделанной работе — проект НПТ

Дата: 22 июля 2026. Два продукта: сайт «Тропа» (`tropa.fmin.xyz`) и Telegram-бот
«Путеводитель по научной тропе».

---

## Часть I. Сайт «Тропа»

### 1. Методичка учителя — качество ответов (после встречи с Гасниковым)
- **Задача:** методичка должна давать точный, «приземлённый» материал без ошибок и мусора —
  репутационное требование Гасникова, ошибки недопустимы.
- **Сделали:** собрали генерацию с опорой на источники (сюжеты + школьная программа + веб);
  выстроили приоритет — образовательный материал первичен, сюжеты вторичны; заменили Википедию
  научными первоисточниками; довели до презентационного вида (план урока, два уровня подачи,
  формулы, погода, иллюстрации с проверкой).
- **Итог:** методичка уходит точно в тему, опирается только на проверенные источники,
  оформлена как PDF.

### 2. Веб-источники — жёсткая фильтрация
- **Задача:** в опору просачивался мусор (пиратский киносайт, Википедия, источники вне списка).
- **Сделали:** жёсткая фильтрация по доверенному списку на своей стороне (фильтр поисковика
  оказался ненадёжным — он «пожелание», а не гарантия); список расширили до 12 научпоп
  и образовательных доменов.
- **Итог:** проходят только доверенные источники, проверено на бою.

### 3. Гео-режим карты маршрута — закрыт целиком
- **Задача:** карта должна показывать пользователя и вести к точкам тропы.
- **Сделали:** гео-чат «Рядом», центрирование на пользователе («Я здесь»), пеший маршрут
  «от меня» до ближайшей точки с дистанцией и временем.
- **Итог:** все фазы (0–3) готовы, подтверждено на реальном браузере.

### 4. Убрали кнопку «Текст (.txt)»
- **Задача:** убрать экспорт в .txt со страницы учителя.
- **Сделали:** удалили кнопку и обработчик, PDF оставили.
- **Итог:** в действиях только «Скачать методичку (PDF)», проверено на реальном уроке.

### 5. База знаний и git
- **Сделали:** весь код в репозитории сайта + зеркало; обновили Obsidian-базу (LOG за
  2026-07-22, разделы «Сделано» в заметках «Сайт НПТ» и «Верификация контента»).
- **Итог:** обе базы чистые, всё запушено.

## Часть II. Telegram-бот «Путеводитель по научной тропе»

### 1. Базовый функционал — голосовой ИИ-гид
- **Задача:** бот, которому задаёшь научный вопрос голосом или текстом и получаешь голосовой
  ответ в стиле русского научпопа (Перельман, Ливанов, «Квант») — прототип для Гасникова,
  демо на ПМЭФ.
- **Сделали:** пайплайн голос → Groq Whisper (STT) → Claude Code (opus) с RAG по выверенной
  базе → голос. Ответ обязательно называет научный принцип явления, а не пересказывает
  банальность.
- **Итог:** работает в Telegram, отвечает и голосом, и текстом в два уровня
  (любознательным / продвинутым с формулами).

### 2. Голос (TTS)
- **Задача:** нужен естественный русский голос без «плывущих» ударений.
- **Сделали:** ушли с ElevenLabs (проблемы с ударениями на кириллице) на Yandex SpeechKit
  (голос filipp), отдаём oggopus напрямую без ffmpeg, retry при сбоях, чистка markdown
  и эмодзи перед озвучкой.
- **Итог:** надёжная голосовая выдача мужским голосом, A/B-подбор голоса.

### 3. Личность и качество ответов
- **Задача:** ответы должны быть в манере научпоп-рассказчика, без AI-воды, без галлюцинаций —
  под требования Гасникова.
- **Сделали:** прописали личность «Профессора» (`CLAUDE.md`) + методологию `scipop-answer`
  (канон, «поперечное сечение реальности», адаптивность под уровень); анти-AI-слоп-фильтры;
  RAG по 40 сюжетам единой базы + справки-первоисточники против галлюцинаций.
- **Итог:** ответы держат научный ракурс и голос, опираются на выверенный контент.

### 4. Геолокация
- **Задача:** бот должен понимать, где стоит пользователь, и рассказывать про ближайшую точку.
- **Сделали:** команда `/location` с кнопкой запроса геопозиции; подбор ближайших сюжетов
  по Haversine (на TDD); работает для любой точки, не только наших; пороги настроены
  (наши точки — до 5 км, мягкое упоминание — до 30 км); промпт запрещает выдумывать
  несуществующие точки.
- **Итог:** гео-привязка работает, точка определяется корректно.

### 5. Инфраструктура
- **Задача:** запустить недорого и воспроизводимо.
- **Сделали:** claude-tg (форк) на VPS, ядро — Claude Code по OAuth-подписке (не API-биллинг),
  воспроизводимые патчи каркаса, `setup.sh` для развёртывания, монорепо (бот в `tg-bot/`),
  контент из единой базы знаний, зеркало на сайте.
- **Итог:** бот развёрнут и работает; секреты только в `.env` на сервере.
