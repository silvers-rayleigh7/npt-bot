# Дизайн-система «Тропа» — MASTER

Источник — эталон «Научные тропы», утверждённый заказчиком (ТЗ). Значения перенесены
точно; менять только вместе с эталоном. Рабочая реализация — `site/assets/tokens.css`.

## Якорь

**Этот сайт — тот, где скролл превращается в шаг по тропе.**

Страница разворачивается как прогулка: секции — остановки на маршруте, между ними
прочерчивается линия тропы, точки-остановки загораются по мере приближения. Отсюда
следует, что анимации появления **не одинаковые**: каждая работает на смысл своего
блока (остановка загорается, карточки выходят каскадом, цифры дорастают до значения).
Одинаковая анимация на всём — анти-паттерн и сразу читается как шаблон.

## Токены

Палитра, типографика, тени, easing — в `site/assets/tokens.css`, там же комментарии.
Кратко: поверхности paper/milk/sand/mist/meadow, текст ink/ink-soft, акценты парами
sky/grass/terra/violet/teal/sun/coral. Шрифты — Unbounded (заголовки), Golos Text
(текст), JetBrains Mono (метки и цифры), все локальные, с кириллицей.

## Что взято из базы и что отклонено

| Из выдачи search.py | Решение |
|---|---|
| Типографика Inter | отклонено — шрифты заданы утверждённым ТЗ |
| Glassmorphism, backdrop blur, light reflection | отклонено — чужой для бумажной тёплой палитры эталона; размытие оставлено только у липкой шапки, чтобы контент читался под ней |
| «Avoid: excessive animation» | взято — движения медленные и редкие, параллакс только на декоре |
| Чек-лист сдачи (контраст 4.5:1, focus, reduced-motion, 375/768/1024/1440) | взято целиком |
| Каскад 400–700 мс, easing expo.out | взято, реализовано на CSS без GSAP |
| Параллакс только для фоновых слоёв, никогда для текста | взято как правило |

## Правила движения

- Анимируем только `transform` и `opacity`.
- Первый экран не «проявляется» — до него не скроллят, он виден сразу.
- Скрытие до появления включается только под классом `.js-reveal`, который скрипт
  ставит сам. Без скрипта страница читается целиком.
- `prefers-reduced-motion` выключает движение полностью, контент остаётся на месте.

## Границы

Контраст текста ≥ 4.5:1, видимый focus, клавиатура работает, вёрстка не ломается
на 375px, тач-цели ≥ 44px.
